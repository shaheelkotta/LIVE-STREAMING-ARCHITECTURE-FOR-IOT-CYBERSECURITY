# LIVE-STREAMING-ARCHITECTURE-FOR-IOT-CYBERSECURITY
Engineered a 5-layer, real-time IoT threat detection pipeline using Python, Apache Kafka, Flink, TimescaleDB, and Grafana. Implemented stateful Complex Event Processing (CEP) to analyze network telemetry in-motion, detecting DoS floods, Data Exfiltration, and Replay attacks with sub-100ms latency while providing live SOC dashboard visibility.
